**Permutaciones** 
- Voto preferencial completo (segunda vuelta instantánea)
	- Cantidad de configuraciones al ordenar ${}n{}$ elementos ${}\equiv P_{n}=n*(n-1)*(n-2)*\dots*1=n!{}$

**Variaciones**
- Voto preferencial opcional/semi-opcional
	- Elección y ordenamiento de un subconjunto entre ${}n{}$ elementos
		- En el semi-opcional existe un mínimo
	- Suponiendo caso semi-opcional y el conjunto de tamaño ${}r,{}$ ${}V_{n,r}=n*(n-1)*(n-2)*\dots*(n-r+1)=\dfrac{n!}{(n-r)}{}$
		- ${}P_{n}=V_{n,n}{}$  ya que la permutación es una variación en un conjunto de ${}n{}$ elementos
		- ${}V_{n,r}=V_{n,m}*V_{n-m, r-m}:m<n{}$

**Combinaciones**
- Votación plurinominal
	- Elección de un subconjunto no ordenado de ${}r{}$ elementos entre ${}n{}$ elementos
		- Todas las ordenaciones de un subconjunto son iguales. Estamos eligiendo ${}r{}$ y el orden nos es indiferente por lo que es 
$$
	‌	  C_{n,r}=V_{n,r} / P_{r}= \dfrac{n!}{(n-r)r!}= \dbinom{n}{r}
	 $$
  - Es decir, cogemos todas las variaciones (los subconjuntos de tamaño ${}r{}$ ordenados), y se divide entre las permutaciones (la cantidad de órdenes) 

**Combinaciones con repetición**
- Votación acumulativa 
	- Se escoge un subconjunto en el que cada elemento ${}n{}$ se repite ${}r{}$ veces
	- El orden es indiferente pero puede haber repetición
		- Número de combinaciones si se puede repetir
	- Por la complejidad de estos ejercicios se suelen plantear de otra forma
		- Tenemos ${}(n-1){}$ barras (separadores entre elementos)
		- Se construyen palabras con caracteres, definiendo un caracter que representa las opciones (barras) y otro que representa las repeticiones por elemento
		- Se cuentan cuántas formas hay de poner ${}r{}$ elementos en un conjunto de tamaño ${}(r+n-1)\equiv \dbinom{n+r-1}{r}{}$
	- ${}CR_{n,r}=C_{n+r-1,r}= \dfrac{(n+r-1)!}{r!(n-1)!}{}${

**Variaciones con repetición**
- Cantidad de palabras de ${}r{}$ letras que se pueden construir con ${}n{}$ letras 
	- El orden importa pero puede haber repeticiones ${}n*n*\dots*n=n^{r}{}$ 

**Resumen**
- ¿Importa el orden?
	- SI - ¿Se permiten repeticiones? 
		- SI - ${}VR_{n,r}=n^{r}{}$
		- NO - ${}V_{n,r}=\dbinom{n}{n-r}!{}$
	- NO - ¿Se permiten repeticiones?
		- SI - ${}CR_{n,r}= \dbinom{n+r-1}{r}{}$
		- NO - ${}C_{n,r}=\dbinom{n}{r}= \dfrac{n!}{(n-r)!r!}{}$

**Coeficiente binomial**
- ${}\dbinom{n}{r}{}$ se llama coeficiente binomial. Tiene las siguientes propiedades
	1. ${}\dbinom{n}{r}=0\text{ si }r>n{}$
	2. ${}\dbinom{n}{r}=\dbinom{n}{n-r}{}$
	3. ${}\dbinom{n}{n}=\dbinom{n}{0}=1\implies 0! = 1{}$
	4. ${}\dbinom{n}{1}=n{}$
	5. ${}\dbinom{n}{r}=\dbinom{n-1}{r-1}+\dbinom{n-1}{r}{}$

**Teorema binomial**
- ${}\forall n\in \mathbb{N}{}$
$$\begin{align}
(a+b)^{n}=\sum ^{n}_{i=0}\dbinom{n}{i}a^{n-i}b^{i}\implies(a+b)^{2}=a^{2}+b^{2}+2ab , \ (a+b)^{3}=\dots
\end{align}
$$
- Corolarios:
	1. ${}2^{n}=\sum ^{n}_{i=0}\dbinom{n}{1}\implies{}$ Poner ${}a=b=1{}$
	2. ${}\sum ^{n}_{i=0}(-1)^{i}\dbinom{n}{i}=0\implies{}$ Poner ${}a=1, b=-1{}$

**Principio de inclusión-exclusión**
- ${}\left|A\cup B \right|=\left| A \right|+\left| B \right|-\left| A\cap B \right|{}$
- ${}\left| A\cup B\cup C \right|=\left| A \right|+\left| B \right|-(\left| A\cap B \right|+\left| A\cap C \right|+\left| B\cap C \right|)+\left| A\cap B \cap C \right|{}$
	- Esto se demuestra con combinaciones, tomando conjuntos ${}A_{1},\dots,A_{n}{}$. Todos los posibles subconjuntos ${}=p(\{1,\dots,n\}){}$
	- ${}p_{K}(\{1,\dots,n\})\subset p(\{1,\dots,n\}){}$
$$
\left| \cup_{i=1}^{n}A_{i} \right|=\sum ^{n}_{j=1}(-1)^{j-1}\alpha_{j}; \ \alpha_{j}=\sum \left| \cap_{i\in I} A_{i}\right|:I\in p_{K}(\{1,\dots,n\}) \wedge p_{R}(B)= \{B\in p(B)| \ \left| B \right|= R\}
$$
- Supongamos que ${}a{}$ es miembro de exactamente ${}r{}$ de los conjuntos ${}A_{1},..,A_{n}{}$. Se cuenta este elemento
	1) ${}\dbinom{r}{1}{}$ veces en ${}\alpha_{1}=\sum \left| A_{j} \right|{}$
	2) ${}\dbinom{r}{2}{}$ veces en ${}\alpha_{2}=\sum \left| A_{i}\cap A_{j} \right|{}$
	3) ${}\dbinom{r}{3}{}$ ceves en ${}\alpha_{3}=\sum \left| A_{i}\cap A_{j}\cap A_{R} \right|\dots{}$
	- ${}\dbinom{r}{m}{}$ veces en ${}\alpha_{m}=\sum_{\left| 1 \right|=m}\left| \cap_{j\in I}A_{j} \right|{}$

- Entonces en la fórmula, el elemento ${}a{}$ se cuenta ${}\dbinom{r}{1}-\dbinom{r}{2}+\dots+(-1)^{r+1}\dbinom{r}{r}{}$ veces. Sabemos que ${}\dbinom{r}{0}-\dbinom{r}{1}+\dots+(-1)^{r}\dbinom{r}{r}=0\implies \dbinom{r}{0}=1\implies 1-(\dbinom{r}{1}-\dbinom{r}{2}+\dots+(-1)^{r}\dbinom{r}{r})=0\implies\dbinom{r}{1}-\dbinom{r}{2}+\dots+(-1)^{r}\dbinom{r}{r}=1{}$

**Permutaciones circulares**
- En una permutación circular, el primer elemento y el último son iguales por la simetría rotacional. De esa forma, las ordenaciones tomadas de una manera concreta son equivalentes (cada elemento circular corresponde a ${}n{}$ elementos lineales). Por tanto, el número de posibles ordenaciones es ${}\dfrac{n!}{n}=(n-1)!{}$

**Permutaciones con repetición**
- En las permutaciones con repetición se toma un multiconjunto en el que cada elemento aparece repetido un número de veces. De esa manera, las posibles ordenaciones son la cantidad del número de elementos (es decir, ${}n!{}$) entre las multiplicidades de cada elemento distinto
	- ${}\dbinom{n}{n_{1}*\dots*n_{k}}{}$
- Se puede caracterizar una permutación con repetición como una manera de distribuir ${}n{}$ objetos distinguibles (el número de elementos) en ${}k{}$ categorías distinguibles (el número de categorías) asignando ${}n_{i}{}$ objetos a la categoría ${}i:1\leq i\leq k{}$
	- ${}\dbinom{n}{n_{1}*\dots*n_{k}}=\dbinom{n}{n_{1}}\dbinom{n-n_{1}}{n_{2}}\dots \dbinom{n-(n_{1}+n_{2}+\dots+n_{k-2})}{n_{k}}{}$

**Coeficiente multinomial**
$$
\dbinom{n}{n_{1},n_{2},\dots ,n_{k}}=\dfrac{n!}{n_{1}!n_{2}!\dots n_{k}!}; \\[2ex](x_{1}+x_{2}+\dots+x_{k})^{n}=\sum_{0\leq n_{i}\leq n\\ n_{1}+n_{2}+\dots+n_{k}=n}\dbinom{n}{n_{1},n_{2},\dots, n_{k}}x_{1}^{n_{1}} x_{2}^{n_{2}} \cdots x_{k}^{n_{k}}
$$

**Conteo por filas y columnas**
- Este problema se emprea para contar el número de elementos de una relación ${}R\subseteq X\times Y{}$, es decir, ${}\left| R \right|{}$ 
	- Se emplea una matriz ${}(M_{R})_{ij}=I_{R}(x_{i},y_{j}):{}$  ${}a_{ij}=0{}$ si  ${}(x_{i},y_{j})\notin R{}$ y ${}a_{ij}=1{}$ si ${}(x_{i},y_{j})\in R{}$
$$
  \left. \begin{array}{ll}
  \text{Filas: }  & \left| R \right|=\displaystyle\sum ^{m}_{i=1}\left| R_{i}  \right|=\sum_{x\in X}\left| R(x) \right| \\[2ex]
  \text{Columas: }  & \left| R \right| = \displaystyle\sum ^{n}_{j=1}\left| R_{j} \right|=\sum_{y\in Y}\left| R^{-1}(y) \right|
  \end{array}
  \right\}
  $$
