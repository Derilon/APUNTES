**Estructura**
- Los sistemas secuenciales complejos se especifican usando un controlador y una ruta de datos
![[Pasted image 20261126180815.png]]
- Las rutas de datos están compuestas por módulos secuenciales y combinacionales. Asimismo existen
	1) Señales de control

**Modelo de cómputo**
- Se pueden ejecutar instrucciones en paralelo, optimizando así los circuitos
-  La ruta de datos se diseña para que pyeda efectuar una serie de transferencias entre sus registros
	- El valor de las señales de control determina cual o cuales efectúa
	- En los módulos secuenciales, se debe especificar la entrada. Un 0 mantiene el estado y un 1 cambia el estado, por lo que un DC es comportamiento indefinido

- El controlador secuencia las transferencias para efectuar un algoritmo
	- Las rutas de datos restringen la posibilidad de realizar operaciones en paralelo

**Metodología de diseño**
- Se emplea la metodología RLT (Register Transfer Level)
	1) Se especifica la funcionalidad
	2) Se dieña la ruta de datos
	3) Se reformula el algoritmo como transferencias entre registros
	4) Se diseña y optimiza el controlador
	- Todos los circuitos tienen una señal de inicio y otra de fin
