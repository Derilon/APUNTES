**Definición**
	- Se llama espacio vectorial (e.v.) sobre ${}\mathbb{R}{}$ a un conjunto ${}E{}$ no vacío con dos operaciones:
	- Suma ${}+:E\times E \to E{}$ que cumple las siguientes propiedades:
		1. Asociativa
		2. Conmutativa
		3. Existe elemento neutro
		4. Existe elemento opuesto
	- Producto externo ${}*:\mathbb{R}\times E\to E|{}$
		1. ${}\lambda*(x+y)=\lambda*x+\lambda*y{}$
		2. ${}(\lambda+\mu)*x=\lambda*x+\mu*x{}$
		3. ${}\lambda*(\mu*x)=(\lambda*\mu)*x{}$
		4. ${}1*x=x{}$

**Sistema generador**
	- Un conjunto de vectores ${}\{x_{1},\dots,x_{n}\}\subset E{}$ es un sistema generador si ptodos los vetores de ${}E{}$ se pueden obtener como combinación lineal de ${}\{x_{1},\dots,x_{n}\}\subset E\to{}$ Es sistema generador si ${}\forall w\in E\ \exists \ \alpha_{1},\dots,\alpha_{n}\in \mathbb{R}|\alpha_{1}x_{1}+\dots+\alpha_{n}x_{n}=w{}$
	- Propiedades: ${}\forall x,y\in E,\forall\lambda,\beta \in \mathbb{R}{}$
		1. ${}0*x=0_{E}{}$
		2. ${}(-\lambda)*x=\lambda*(-x)=-(\lambda*x){}$
		3. ${}\lambda*(x-y)=\lambda*x-\lambda*y{}$
		4. ${}(\lambda-\beta)*x=\lambda*x-\beta*x{}$
		5. Si ${}\lambda*x=0_{E}\implies\lambda=0\text{ ó }x=0_{E}{}$

**Combinaciones lineales**
	- Sean ${}x_{1},\dots,x_{n}{}$ n vectores de ${}E\text{ e.v.}{}$ Dados n números reales cualesquiera${}\lambda_{1},\lambda_{2},\dots,\lambda_{n}{}$, una combinación lineal de ${}x_{1},\dots,x_{n}{}$ es ${}\lambda_{1}x_{1}+\lambda_{2}x_{2}+\dots+\lambda_{n}x_{n}{}$

**Dependencia e independencia lineal**
	- Un conjunto de vectores de un espacio vectorial ${}E{}$ es linealmente independiente si la única combinación lineal que da el elemento neutro es con todos los escalares cero${}\to\text{ Si }\alpha_{1}x_{1}+\alpha_{2}x_{2}+\dots+\alpha_{n}x_{n}=0_{E}\implies \alpha_{1}=\alpha_{2}=\dots=\alpha_{n}=0{}$
	- Si no son linealmente independientes (l.i.) decimos que son linealmente dependientes (l.d.)

**Bases**
	- Un conjunto de vectores ${}\{x_{1},\dots,x_{n}\}\subset E{}$ es una base de un ${}e.v.{}$ si es un sistema generador y si es linealmente independiente
		1. Un ${}e.v. \ E{}$ generado por un número finito de vectores tiene base
		2. Si ${}\{v_{1},\dots,v_{n}\}{}$ es una base de un ${}e.v.{}$, cada vector ${}w\in E{}$ se puede expresar de modo único como combinación lineal de los vectores de la base, es decir, existe una única familia de números ${}\alpha_{1},\dots,\alpha_{n}|\ \alpha_{1}v_{1}+\dots+\alpha_{n}v_{n}=w{}$. Cada uno de los valores de alfa se llaman coordenadas del vector ${}w{}$ en la base ${}B=\{v_{1},\dots,v_{n}\}{}$ y se denota ${}w=(\alpha_{1},\dots,\alpha_{n})_{B}{}$ 
	- Una base canónica de un espacio vectorial ${}\mathbb{R}_{n}{}$ si está compuesta de n vectores ${}(v_{i},\dots,v_{i}){}$ tal que tiene el mismo número de elementos que n y tiene un 1 en su posición i-ésima y cero en los demás
