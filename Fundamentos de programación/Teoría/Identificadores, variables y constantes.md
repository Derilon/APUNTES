**Identificadores**
	- "Nombres" de las variables
	- Deben empezar por una letra o un guión bajo
	- Evitar caracteres especiales (ñ o vocales acentuadas)
	- Existen palabras que no se pueden usar por ser instrucciones u otras cuestiones

**Variables**
	- Las variables son un contenedor de datos que se mantienen en memoria al que se accede por medio de un nombre 
	- Deben ser declaradas antes de poder ser usadas
	- Pueden tener modificadores: [modificadores] tipo lista_de_variables;
		* Ejemplos: short, long, unsigned, double, etc...
	- Si varias variables son del mismo tipo se pueden definir en la misma línea entre comas
	- Como consejo, la primera abreviatura en minúscula y las segundas abreviaturas con la primera en mayúscula
	- Cada variable necesita cierta memoria, se reserva
	- Declarar las variables antes del inicio de un bloque de código. Cada bloque solo puede usar sus variables locales
	- Se pueden declarar valores auxiliares (aux). Sirve, por ejemplo, para intercambiar variables

‌	**Constantes**
	- Modificador de acceso const
	- Variables inidializadas a las que no dejamos variar - no podrán volver a aparecer a la izquierda de un =
