**Tipos de datos**
		- Cada tipo establece el intervalo de valores válidos y el conjunto de operaciones que se pueden realizar con ese tipo. 
	- Int: números enteros
	- Float: números reales – 7 decimales
	- Double: números reales (mayor intervalo y precisión) - 15 decimales
	- Char: caracteres
	- Bool: 1/0 - usar true o false
	- Void: ausencia de tipo
	- String: cadenas de caracteres (biblioteca string) - entre comillas
		* Signed/insigned: con o sin signo
		* Short/long: menor o mayor intervalo de valores 

**Conversiones de datos**
	- Conversiones automáticas: cuando en una operación coinciden dos operandos. El valor del tipo menor se promociona al tipo mayor, no cambia el tipo de la variable
	- Conversiones seguras: de un tipo mejor a un tipo mayor
	- Conversiones no seguras: de un tipo mayor a uno menor
	- Moldes: Fuerzan una conversión de tipo (del valor)
	- static_cast< tipo >(variable) ${}\to {}$ Conversiones explícitas
